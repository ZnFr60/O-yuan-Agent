## 二、关键收获与吸收评估

### 1. 缓存命中率优化（已吸收）

- **观察**：各框架对重复请求普遍缺乏缓存；业界强调最大化 LLM 利用率。
- **本项目做法**：LRU+TTL 混合淘汰 + 请求归一化哈希 + 语义模糊命中（余弦相似度共享结果），
  缓存 Key 覆盖 输入/角色/思考等级/KB 片段/合议配置，任一变即失效。
- **评估**：不冲击顶层架构，已落地。

### 2. 模块化功能开关（已吸收）

- **观察**：Agno/OpenManus 均强调组件可组合、可替换；非必要功能应可关闭。
- **本项目做法**：`features.js` 集中注册表，14 项功能独立开关，关闭即不执行逻辑；前端“功能开关”面板。
- **评估**：不冲击顶层架构，已落地。

### 3. OpenAI 兼容 API 出口（已吸收）

- **观察**：主流框架普遍提供标准协议出口以兼容生态工具。
- **本项目做法**：`/v1/chat/completions` + `/v1/models`，复用内部合议/缓存/角色/RAG 全链路，支持流式。
- **评估**：不冲击顶层架构，已落地。

### 4. 主流模型适配档案（已吸收）

- **观察**：不同模型上下文/温度上限/参数约束差异大（如 o1 固定温度）；粗暴传参易失败。
- **本项目做法**：`model-profiles.js` 内置 DeepSeek/OpenAI/Claude/Gemini/Qwen/GLM/Llama 等 30+ 档案，
  自动 clamp 温度、校准 max_tokens。
- **评估**：不冲击顶层架构，已落地。

### 5. 人格档案 MD 化（已吸收）

- **观察**：用户要求“自定义人格形象，风格写在一个 .MD 文件中”；OpenClaw 强调配置即代码。
- **本项目做法**：`config/roles/*.md` 支持 名称/形象/语气/问候语/回答风格/行为准则/禁止行为/头像，
  Web UI 可新建/编辑/删除，切换即时生效。
- **评估**：不冲击顶层架构，已落地。

### 6. 异步任务队列与看板（已吸收）

- **观察**：复杂 Agent 需要并发控制与可观测性。
- **本项目做法**：并发上限/排队/超时丢弃/状态看板，Web 面板展示。
- **评估**：不冲击顶层架构，已落地。

## 四、对业界主流 Agent 框架的具体观察（作为参考素材，非本项目来源）

- 业界主流 Agent 框架的“长期目标持久化（goal）”“跨会话续跑”思路值得借鉴：本项目后续可在会话层增加持久化。
- 业界主流 Agent 框架的工程落地方式（目录结构、模块化、日志、Git 管理）与本项目规范一致，仅作工程实践参考。
